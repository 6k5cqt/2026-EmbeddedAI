# 개요
한양대학교 미래자동차공학과
2026 AUE4040 프로젝트 자료입니다.

# 설명
- 프로젝트는 Track_Announcement의 테스크를 수행하는 것과, YourOwnProblem 두 단계로 이루어짐
- 현재는 YourOwnProblem의 drivable area 주행 코드로 변경된 상태
- 기존의 도로 차선인지 + task 수행 코드는 _road로 백업되어 있음
- Drivable area yolo 학습 코드는 yolo_drivable_learner에 있음 (w/o dataset)
- report에 중간, 최종 보고서 첨부
